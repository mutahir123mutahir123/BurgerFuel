Phase 6 — Cart State & Cart Drawer

Once product configuration works, build the cart.

I'd use a dedicated cart context/store rather than passing cart state through:

App
 ↓
Navbar
 ↓
Menu
 ↓
ProductCard
 ↓
Modal
 ↓
...

That would create unnecessary prop drilling.

Instead:

CartProvider
       │
       ├── addItem()
       ├── removeItem()
       ├── updateQuantity()
       ├── clearCart()
       ├── subtotal
       └── totalItems

Then any component that genuinely needs cart information can consume it.

One architectural rule I'd add

I would make Phase 0 the foundation for everything, particularly the product configuration model. Your menu isn't just name + price: it has normal prices, pizza sizes, quantity variants, wrap sauce selection, extra toppings, and add-ons.

If we design that model correctly first, the UI becomes much cleaner:

Menu Data
    ↓
Product Card
    ↓
Product Modal
    ↓
Configuration
    ↓
Cart Item
    ↓
Checkout
    ↓
Order
